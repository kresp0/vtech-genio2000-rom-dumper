# Photographs

All photographs in this directory were taken by the repository author, and the annotations on them were drawn by the author's
tooling. They show the cartridge **"Inglés para principiantes"** (PCB 701243C).

## Files and preferred form for modification

| File | Description |
|---|---|
| `cartridge_pcb_component_side_original.jpg` | Original cartridge, component side, original ROM fitted (before modification). **Source** of the annotated version. |
| `cartridge_pcb_component_side_annotated.jpg` | The same with pin numbers and English labels. Derived. |
| `cartridge_pcb_copper_side_original.jpg` | Original cartridge, copper side, ROM removed (before modification). |
| `modified_cartridge_copper_side.jpg` | Modified cartridge, copper side. **Source** of the annotated version. |
| `modified_cartridge_copper_side_annotated.jpg` | The same with pad numbers and English labels. Derived. |
| `modified_cartridge_component_side.jpg` | Modified cartridge, component side with the DIP-28 socket and AT28C256-15PI; cropped and rotated 180° from the uncropped original. Source of the annotated version. |
| `modified_cartridge_component_side_annotated.jpg` | The same with English labels. Derived. |
| `source/modified_cartridge_component_side_uncropped.jpg` | The uncropped photograph as taken (rotated 180° relative to the other photographs; a paper label with Spanish text is visible in the cartridge shell). **Preferred source** for the two images above. |

The plain (unannotated) images are the preferred form for making modifications; annotations are overlays and can be redrawn.
Metadata (EXIF) was removed from the published files and they were re-saved as JPEG at quality 90 to 92; the camera originals
with their metadata remain in the author's archive.
